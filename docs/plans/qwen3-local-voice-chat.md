# เพิ่มแชต Qwen3 พร้อมเสียงภาษาไทยในเครื่อง

### สรุป

ใช้ `qwen3:4b` ผ่าน Ollama เพื่อคิดคำตอบ และ **Wayu-Paxa-TTS-Edge** สร้างเสียงบน CPU ในเครื่องเดียวกับบอต รองรับไทย อังกฤษ และข้อความผสม เหมาะกับการใช้ส่วนตัวตามที่เลือก โดยโมเดลเสียงมีเงื่อนไขไม่ใช้เชิงพาณิชย์ ([ข้อมูลผู้พัฒนา](https://github.com/wayu-research/wayu-tts-inference))

ลำดับการทำงาน: **ข้อความ Discord → Qwen → คำตอบข้อความ → Local TTS → ห้องเสียง**

### พฤติกรรมบอต

- รับข้อความผ่าน `@บอต ข้อความ` และ `/chat message` ในเซิร์ฟเวอร์ โดยข้ามข้อความจากบอตและ webhook
- ตอบภาษาไทยเป็นหลัก ใช้ภาษาอังกฤษเมื่อผู้ใช้ขอหรือสนทนาเป็นภาษาอังกฤษ ตอบกระชับเหมาะกับการอ่านออกเสียง ยังไม่กำหนดบุคลิก
- ส่งคำตอบข้อความก่อน แล้วพูดในห้องเสียงของผู้ใช้ หากผู้ใช้ไม่ได้อยู่ในห้องเสียงให้ตอบเฉพาะข้อความ
- หากบอตกำลังอยู่คนละห้องเสียง ให้ตอบข้อความพร้อมแจ้งเหตุผล โดยไม่ย้ายห้องอัตโนมัติ
- จำบทสนทนาแยกตามเซิร์ฟเวอร์ ห้องแชต และผู้ใช้ เก็บใน RAM สูงสุด 10 คู่ข้อความ หมดอายุเมื่อเงียบ 30 นาที และล้างได้ด้วย `/chat-reset`

### การเชื่อมระบบ

- เพิ่มบริการแชตเรียก Ollama ที่ `http://127.0.0.1:11434` ใช้ `qwen3:4b`, `think:false`, `stream:false` และ timeout 120 วินาที ส่งเฉพาะคำตอบสุดท้ายให้ TTS
- เพิ่มบริการ Python สำหรับ Wayu ใน virtual environment แยก โหลดโมเดลครั้งเดียวบน CPU ใช้เสียงเริ่มต้น `f_young_clear` ความเร็ว 1.0
- บริการเสียงเปิดเฉพาะ `127.0.0.1:8788` มี `GET /health` และ `POST /synthesize` รับ `{text, voice?}` ส่งกลับ WAV แบบ PCM 16-bit mono 24 kHz
- เพิ่ม TTS provider `local` ให้เข้ากับระบบคิวเสียงและการพักเพลงเดิม ตั้งค่า URL และเสียงผ่าน environment variables
- จำกัดข้อความเข้า 2,000 ตัวอักษร และคำตอบสำหรับพูด 1,000 ตัวอักษร ตัดตามขอบเขตประโยค พร้อมล้าง Markdown ที่ไม่เหมาะกับการอ่าน
- ประมวลผลคำขอแชตทีละรายการ คิวรอสูงสุด 5 รายการ แจ้งเมื่อคิวเต็ม และตรวจห้องเสียงผู้ใช้อีกครั้งก่อนเล่น
- เมื่อ Ollama หรือ TTS ล้มเหลว แจ้งเป็นภาษาไทย; ถ้าสร้างคำตอบได้แล้วให้คงข้อความไว้ ไม่มีการเปลี่ยนไปใช้บริการเสียงออนไลน์อัตโนมัติ
- เพิ่มสคริปต์ติดตั้ง ดาวน์โหลดโมเดล และเปิด/ปิดบริการเสียง พร้อมเอกสารตั้งค่า Discord สำหรับรับข้อความแท็กบอต

### การทดสอบและค่าเริ่มต้น

- ทดสอบแชตภาษาไทย อังกฤษ ข้อความผสม การสนทนาต่อเนื่อง และการล้างความจำ
- ทดสอบการแยกบริบทระหว่างคน/ห้อง คิวเต็ม timeout บริการไม่พร้อม และเสียงว่าง
- ทดสอบผู้ใช้ออกจากห้องหรือย้ายห้องระหว่างรอ รวมถึงการเล่นเสียงร่วมกับเพลง
- ดาวน์โหลด dependency และโมเดลล่วงหน้า แล้วตรวจว่าการคิดคำตอบและสร้างเสียงทำงานได้โดยไม่เรียกบริการภายนอก; Discord ยังต้องใช้อินเทอร์เน็ต
- รัน `npm run check`, `npm run build:all` และทดสอบบริการ Python ก่อนทดสอบจริงใน Discord
- วัดเวลาสร้างเสียงและการใช้ RAM บนเครื่องจริงก่อนสรุปความเร็ว ใช้ CPU เป็นค่าเริ่มต้นสำหรับ TTS; ยังไม่เพิ่มรับเสียงไมโครโฟน หน้าแดชบอร์ด หรือความจำถาวร
